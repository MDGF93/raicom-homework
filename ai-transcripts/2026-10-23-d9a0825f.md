### Claude

The pre-commit and pre-push hooks are set up, and they block when something fails. Both hooks run `npm run check`, which runs `prettier --check`, then `eslint src`, then `npm test`. If any step fails, the commit or push stops.

I ran the hooks with `git hook run` and got these results:
- Clean tree: both hooks exit 0.
- A badly formatted file: pre-commit fails.
- An ESLint error (`no-explicit-any`): pre-commit fails.
- A failing test: pre-push fails. I then put the original test file back.

**What changed:**
- [package.json](package.json): new dev dependencies are `husky`, `prettier`, `eslint`, `@eslint/js`, `typescript-eslint` and `typescript` (ESLint needs `typescript` to read TS files). New scripts:
  - `prepare`: installs the hooks on `npm install`.
  - `format`: runs `prettier --write`. Use it to fix a format failure.
  - `check`: the command the hooks run.
- [.husky/pre-commit](.husky/pre-commit) and [.husky/pre-push](.husky/pre-push) both contain `npm run check`.
- [eslint.config.js](eslint.config.js) uses the ESLint recommended rules and the typescript-eslint recommended rules.
- [.prettierrc.json](.prettierrc.json): `singleQuote` and `printWidth: 140` keep your current style. `endOfLine: "auto"` is there because your `core.autocrlf=true` setting gives CRLF files on checkout, and those would fail the check.
- I ran Prettier once on all 4 files in `src/`, about 210 changed lines. All changes are whitespace and line wrapping, and all 13 tests still pass.

**Limits:**
- Prettier and ESLint check only `src/` and `eslint.config.js`. Markdown files, JSON files and the Raicom data folder are not checked.
- Pre-commit checks your working files, not only the staged changes. An unstaged mistake can block a commit, and a staged mistake can get through if you fixed it later without staging the fix. If you start to commit parts of files often, add `lint-staged`.
- No hook runs a `tsc --noEmit` type check. `tsx` does not check types, so type errors can still get through. Add `tsc --noEmit` to `check` if you want the hooks to catch them.
